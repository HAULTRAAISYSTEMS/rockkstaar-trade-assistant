Grade → token map

  • A+ .g-aplus — --grad-brand fill, --text-on-accent, --glow-accent shadow + 2.4s pulse. Only tier that glows/animates.
  • A .g-a — --grad-brand-soft fill, --orange-400 text, rgba(255,122,24,.6) border.
  • B+ .g-bplus — amber rgba(255,176,32,.14) / --warn-500.
  • B .g-b — --surface-raised / --text-muted, quiet.
  • UNGRADED .g-ungraded — --surface-inset, dashed border, — glyph, dim the whole row to .72.

Rules

  • Font is Rajdhani 700 (display) at every size — never Plex.
  • Card size 23px / min-width 66px; row size 12px mono-ish weight / min-width 38px.
  • Reserve the pulse + glow for A+ only. If everything glows, nothing does.
  • Never place two A+ badges adjacent without whitespace — they fight.
  • Component: extend <Badge> with a grade prop, or ship a dedicated <GradeBadge grade size>.
