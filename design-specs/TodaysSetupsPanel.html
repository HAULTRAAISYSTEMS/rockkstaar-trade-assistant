Panel spec

  • Fixed ~340px column; shows the top 3 setups by grade → swing score. Never more than 3 — it's a glance, not the scanner.
  • Row grid: grade | ticker+levels | score+status. Levels compressed to E / S / T / R:R mono, faint labels.
  • A+ row gets a subtle left-to-right --grad-brand tint wash so it separates without a full glow (glow is reserved for card size).
  • Whole row is a tap target → prefills the order ticket with entry/stop/target. Hover = --surface-raised.
  • Header pill shows the A+ count; footer links out to the full Setups screen.
  • If 0 setups: collapse to a one-line --text-faint "No setups — patience is a position." (mini empty state, no illustration).
