Layout

  • Shell: <Tabs variant="underline"> for buckets — each tab label carries a count chip; active count chip flips to --grad-brand.
  • Regime strip is a 5-segment flex bar (own component <RegimeMeter>): regime verdict, breadth meter, VIX, SPY trend, session-risk badge.
  • Card grid: repeat(3,1fr) desktop → 1fr below 900px. Gap --sp-4.

Setup card anatomy

  • Header: grade badge + ticker + setup type on the left, price + %chg (pos/neg colored) right.
  • 4-cell mono strip: Entry / Stop / Target / R:R. When a level is unknown show — in --text-faint, never a fake number.
  • Footer: swing-score meter (fill = --grad-brand, degrades to amber→ink→red as score drops) + status badge.
  • Status → <Badge> tone: Ready=positive, Wait=warning/neutral, Do Not Enter=negative. A+ card also gets --border-accent + --glow-accent.

Empty state

  • Fires when the active bucket returns 0. Headline "No A+ Setups", sub "Patience is a position." — discipline copy is intentional, keep it.
  • Always offer a lateral action (View Forming) so the empty state isn't a dead end.
