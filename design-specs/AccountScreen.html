Components

  • KPI row = 6× <Stat> in a repeat(6,1fr) grid (→ repeat(3,1fr) under 1100px). Value = mono, label = --track-label uppercase.
  • Discipline uses a conic-gradient ring (score→fill), colored by band: ≥80 --pos-500, 60-79 --warn-500, <60 --neg-500.
  • Trades Today X/3 renders the cap as 3 slot chips — filled = --grad-brand. At 3/3 the value flips to --warn-500 and Terminal should disable new orders (daily-limit guardrail).
  • Positions = <DataTable> with mono numeric columns; render the grade cell as a row-size <GradeBadge>. P&L / R colored by sign.

Journal + broker

  • Journal rows carry a left .jmark rail colored by outcome (win=pos, loss=neg, avoided=warn) + an outcome <Badge>: Rules held / Broke rule / Avoided. This ties every trade back to discipline.
  • Schwab has two states: Connected (green pill in topbar, "synced Xs ago") vs Connect-prompt (dashed card, primary Connect button). Show the prompt state whenever the token is missing/expired.
